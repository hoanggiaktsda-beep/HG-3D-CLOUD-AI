Thêm vào màn hình chính / tải file

iPhone, iPad: mở bằng Safari → Chia sẻ → Thêm vào Màn hình chính. Windows, macOS: dùng tùy chọn cài ứng dụng của trình duyệt nếu được hỗ trợ. Cài đặt trên thiết bị thật chưa được kiểm chứng.

GLB và BLEND là mẫu công khai. Trên iOS, nếu file mở trong tab mới: Chia sẻ → Lưu vào Tệp. BLEND cần Blender trên máy tính để chỉnh sửa. Ngoại tuyến chỉ xem mẫu đã lưu; tải BLEND cần mạng.

Cloud Worker mẫu: Xem tiến độ và Artifacts thực trên GitHub Actions.

Chỉ dành cho dữ liệu mẫu công khai, yêu cầu đăng nhập GitHub để tải Artifacts; file có thời hạn lưu. Không gửi ảnh đã chọn vào Actions. Kết nối tự động từ website tới Worker riêng: CHƯA KẾT NỐI. Không có tiến độ AI giả.
